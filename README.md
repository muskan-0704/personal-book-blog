# Personal Book Blog & Catalog

A responsive frontend book catalog and review showcase built with semantic HTML5 and CSS3. The page features curated book overviews, character lists, key themes, ratings across platforms, and custom hover overlays.

## Features

- **Semantic Layout**: Clean structuring using `<header>`, `<main>`, `<section>`, and `<footer>` tags.
- **Custom Theme**: Soft pastel color palette styled with custom CSS.
- **Card Hover Effects**: Smooth CSS transitions and overlays on book covers.
- **Fully Responsive**: Media queries optimized for mobile and desktop screens.

## Tech Stack

- **HTML5**
- **CSS3** (Flexbox & Media Queries)
